HOW TO USE
================================================================================

Option 1: Local Validation (NO DOCKER REQUIRED)
   $ bash scripts/validate-build.sh
   
   Output: System requirements check, build, linting, tests

Option 2: Docker Build (DOCKER REQUIRED)
   $ bash scripts/build-docker.sh
   
   Output: Multi-stage images, timestamped, validation logs, sizes

Option 3: Docker Compose
   $ docker-compose build
   $ docker-compose run validator
   
   Output: Orchestrated build and validation

Option 4: Manual Docker Commands
   $ docker build -t uw:latest .
   $ docker run --rm uw:latest node dist/cli.js --help
