# Music and SFX procurement

Underworld Writer intentionally does not ship mystery stock audio.

For every production asset, record: stable asset ID, creator/provider, source, acquisition date, ownership or license type, permitted commercial/podcast/social uses, attribution requirement, territory/term if limited, local runtime path, SHA-256, and approval status.

Prefer commissioned/owned material for recurring show identity (theme, chapter stinger, midroll bumper). Licensed library material is acceptable for beds when the license permits the intended distribution. Public-domain material still needs source/provenance.

Do not mark an asset `approved` merely because it is downloadable or described as royalty-free. Keep receipts/license snapshots outside Git when they contain private account data, and record a durable reference in the registry.

Insight Corruption's registry starts with required slots rather than fake assets. A release render must fail until those slots point to real, cleared files.
