# Music and SFX procurement

Underworld Writer intentionally does not ship mystery stock audio.

For every production asset, record: stable asset ID, creator/provider, source, acquisition date, ownership or license type, permitted commercial/podcast/social uses, attribution requirement, territory/term if limited, local runtime path, SHA-256, and approval status.

Prefer commissioned/owned material for recurring show identity (theme, chapter stinger, midroll bumper). Licensed library material is acceptable for beds when the license permits the intended distribution. Public-domain material still needs source/provenance.

Do not mark an asset `approved` merely because it is downloadable or described as royalty-free. Keep receipts/license snapshots outside Git when they contain private account data, and record a durable reference in the registry.

Insight Corruption's registry starts with required slots rather than fake assets. A release render must fail until those slots point to real, cleared files.

## Self-generated audio (open-weight models, $0 licensing cost)

A fourth, equally legitimate procurement path: generate the asset yourself with an open-weight model whose license grants you commercial ownership of the output, instead of licensing or commissioning it. Insight Corruption's five required assets use this path via `modal/generate_production_audio.py`:

- **Music (theme, investigation bed, reflection bed)** — [ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5), Apache-2.0. Apache-2.0 permits commercial use unconditionally — no revenue threshold, no registration.
- **Short SFX (chapter stinger, midroll bumper)** — [Stable Audio Open 1.0](https://huggingface.co/stabilityai/stable-audio-open-1.0), Stability AI Community License. Free for commercial use **only for organizations with less than USD $1,000,000 in annual revenue**; above that, an Enterprise license from Stability AI is required. Confirm this threshold still applies to Fused Gaming LLC before treating any Stable Audio Open output as cleared — re-check if that changes.

Generation is not clearance. The same rules apply as any other source:

- Record the exact model name and version/revision (not just "ACE-Step" — pin the checkpoint/tag actually used), the model's license, the prompt, the seed, the output duration, and the SHA-256 in the asset's `license` field in `asset-registry.json` — this is this asset's provenance record, structurally the same field a purchased asset's license/receipt would occupy.
- A fixed seed + fixed prompt + fixed model version is what "reproducible" means here — it is not a guarantee the output is usable. Still listen to it (`docs/guides/PRODUCTION_AUDIO.md` step 10) before flipping `status` to `approved`. Nothing in this repo does that for you automatically.
- If a generation violates the show's editorial-restraint rules (`modal/config/production_profiles/investigative-documentary.json`'s `editorialRules` — no sirens/gavels/gunshots/cash-register sounds, nothing that implies guilt) or brief spec, reject it and regenerate with a revised prompt or seed. Do not hand-edit output to "fix" it into compliance and call the original prompt/seed accurate.
- Generated bytes are runtime data, not source: stage them locally under `projects/<show>/production/audio/generated/` (gitignored, never committed), and only push the exact approved bytes to the `underworld-production-audio` Modal volume via `scripts/sync-modal-production-audio.py`, which itself refuses to sync anything not already marked `approved` with a matching checksum.
- The prompts and seeds themselves (not the audio) are small and reviewable, so they live in Git at `projects/<show>/production/audio/generation-prompts.json` — treat changes to that file like any other editorial change, since it's what makes a future regeneration reproducible instead of a fresh roll of the dice.
