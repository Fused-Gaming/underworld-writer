# Voice intake guide

Voice intake is provenance-sensitive. Preserve the original authorized source, derive deterministic runtime references, and record hashes for both.

For Chatterbox, use a clean 10-30 second canonical reference. Keep alternates only for controlled A/B testing. Do not silently swap references between chunks. The project voice profile records consent, source provenance, extraction ranges, conversion parameters, checksums, delivery characteristics, and runtime storage paths.

A profile is not runtime-ready until the exact derived reference bytes exist in the configured Modal volume and their checksum matches the project record. Fine-tuning is an escalation path after zero-shot evaluation, not an automatic intake step.
